Alahinnatud kuulutused

Mudeli jaoks pole veel piisavalt Tallinna andmeid (vaja vähemalt 50 müügi- ja 30 üürikuulutust koordinaatidega). Käivita python run.py või python run.py --import-dir <kaust>.

Mudel: log(€/m²) = kauguse kõver (murdepunktid 2, 5, 8 km) + toad + pind + ehitusaasta + seisukord + korrus, eraldi müügile ja üürile. Keskpunkt on punkt, millest kaugus selgitab müügihinda kõige paremini. Alahinnatud = hind vähemalt 15% alla mudeli hinnangu. Koordinaadid: Maa- ja Ruumiamet (In-ADS). Andmed: kv.ee.
